# 内容发动机：按问题调用能力

作者与账号是方法参照，不是待模仿的文风、事实信源或市场效果保证。名称来自最新系统基线与前一轮矩阵，能力最终汇入 Tang 的独立判断和真实语言。不要代造 Tang 的商业经历、观察或信源。

## 两个不同维度

**传播引擎**回答读者为何点、记住或转发：一篇一个主引擎，最多一个辅助，如认知反转加现实利益。

**内容发动机**回答生产中要补哪项能力：一个主发动机加1—3个确有需要的辅助。按问题和缺口调用，不为了配齐名单加载；事实核验、作者负责的判断、人格审查与品控是共同责任，不要求把所有作者都变成并列风格。

## 能力与越权边界

| 能力／参照 | 何时调用、要产出什么 | 必须守住的边界 |
| --- | --- | --- |
| 全球证据／万维钢 | P5或科学判断：当前最可靠解释、证据质量与边界 | 追到原始研究、综述、更新和重复验证；不把单篇、畅销书或名实验当共识 |
| 机制拆解／半佛仙人 | P6、商业异常：利益、激励、约束、风险、成本、信息和博弈链 | 区分已验证事实、合理推断、假设；匿名信源和内幕感不能代替证据 |
| 中国现实／九边、刘润 | P1/P5/P6：宏观变化如何落到普通人，或商业现场如何产生认知差 | 九边偏结构到处境，刘润偏一线到新认知；不由一家公司、一个老板、一个城市推出全国规律 |
| Tang 判断 | P7：研究与机制之后，一个有边界、可修正、能迁移的核心判断 | 事实、推断、价值判断分开；列最强反例和失效条件，不能止步于知识搬运 |
| 用户情绪／咪蒙 | P1/P2/P9：准确读者问题、访谈线索、入口或标题实验 | 情绪决定待解决的问题，证据决定结论；不制造敌人、虚构苦难或极化情绪 |
| 公共经验／GQ实验室 | 日常、职场、社会观察、朋友圈：具体共同经验及准确描述 | “大家都经历”须有依据；不让梗、刻板印象和笑点扭曲现实 |
| 认知压缩／罗振宇 | P4/P9：可独立携带、准确且有用的名称、模型或判断 | 先证明再命名；名称不等于机制已证实，压缩后保留关键条件 |
| 认知降维／混知 | 抽象机制难懂时：图示构想、对照、流程、空间关系或日常类比 | 明确类比像与不像之处，简化不失真；视觉执行仍按任务和项目授权 |
| 文化熟悉度／六神磊磊 | P5/P9：中文读者已熟悉且贴切的历史、文学、人物或现实案例 | 同时看熟悉度、贴切度、新解释；不把文化故事当科学证明或强套历史类比 |
| 商业故事／兽楼处 | 商业认知或叙事：人、关系、选择与命运显出商业结构 | 信源分级、事实核实、必要匿名与不确定性；故事性不能代替核实 |
| 真实人物／真实故事计划 | 叙事、人生成败、家庭或工作现场：一个复杂完整的人 | 先进入经历与选择；人物优先于观点，主题与事实冲突时修改主题 |
| 普世情绪／视觉志 | 确有真实人物与材料时：共同的人类情感和跨圈层入口 | 只学寻找普遍情感；不复制模板煽情、人物工具化或悲惨竞赛 |
| 作者人格／和菜头 | 初稿与审作者：真实偏好、语言、经验、幽默和判断的辨识度 | 方法增强作者，不替代作者；没有声音样本就不能捏造人格，人格不凌驾事实 |
| 产品与品控／脱不花 | 生产和迭代：用户价值、研究／选题标准、品控、反馈与稳定交付 | 标准化发现、研究、审查与进化；作品保留探索，不固定模板、比例或频率 |

## 认知主链

全球证据 → 机制拆解 → 中国现实 → Tang 判断，构成稳定的认知处理方式；题材可以变化。先按本文的主要难题定主发动机，再选必要辅助。调用意味着完成相应工作，不意味着挨个提到这些作者或让文章像他们。

可供选择的组合：

- 科学认知：全球证据为主，机制、中国现实、认知压缩按需要辅助；最终必须有 Tang 判断。
- 商业认知：机制为主，一线现场、商业故事、全球证据按缺口辅助。
- 社会观察：公共经验为主，用户情绪、宏观结构、认知压缩按需要辅助。
- 认知叙事：真实人物为主，商业故事或机制／研究仅在必要时进入，不能让论文压过人物。
- 朋友圈：作者人格为主，公共经验或认知压缩轻量辅助；不加载全套研究生产链。

## 阶段交接与防错

P1/P2用情绪和公共经验找到已经存在的张力；P5用证据和真实案例核实；P6拆机制并寻找替代解释；P7形成作者负责的判断；P9再做熟悉化、压缩和传播设计；终稿检查作者声音与品控。既有材料可跳过已完成工作，不把这条建议变成所有文体的固定结构。

检查能力是否越权：情绪不能决定事实，研究不能替作者做价值判断，机制推演不能变事实，宏大叙事不能替因果证据，命名不能假装已证明，图解不能失真，故事不能免核实，人格不能覆盖事实，稳定流程不能取消探索。
