# 唐式声音与方法

这份文件用于所有重要写作和改稿任务。它定义稳定方向，不提供必须照抄的句式模板。

## 六个质量问题

不要先问“像不像 AI”。先问下面六件事。

1. 真不真。事实、经历、引语和数字是否站得住。
2. 有没有自己的判断。是否只是复述互联网平均观点。
3. 有没有信息增量。每一部分是否让读者多知道一点。
4. 能不能一直读下去。是否持续产生新问题、解释、变化和认知奖励。
5. 是不是具体的人在说话。是否有知识位置、取舍、边界和愿意承担的判断。
6. 读完以后发生了什么。是否留下新解释、判断框架、情绪释放或行动出口。

把它们当成审稿启发式，不当作可计算的科学模型。任何一项明显缺失时，辞章通常很难完全补救。

## 嘴替感

嘴替感不是替读者骂出来。它是替读者把模糊但真实存在的经验说准确。

使用这条链。

`共同体验 → 隐含矛盾 → 精确命名`

读者先认出“这就是我遇到的事”，随后知道“真正让我难受的是哪一步”，最后得到“下次怎样判断或行动”。不要用情绪迎合代替准确命名。

## 判断先过四关

一篇重要文章先确定一个统领全文的主判断。复杂长文可以有从属判断，但它们必须共同回答同一个核心问题。依次检查主张、证据、最强反方和边界。

主判断要比材料多走一步，又不能跨过证据边界。缺少材料是空话，只做材料汇总没有判断，不能改变理解或行动则缺少写作价值。

不追求强行反常识。加入一个被忽略的条件，让默认解释变得更准确，也是一种足够好的认知奖励。

## 钩子来自内容

只使用能够兑现的五类钩子。

- 事实钩子。出现意料之外但已核实的信息。
- 因果钩子。读者知道结果，还不知道为什么。
- 冲突钩子。两个同时看似成立的事实发生冲突。
- 判断钩子。作者给出明确而值得验证的判断。
- 后果钩子。读者意识到这件事与自己的选择有关。

熟悉摩擦、人话翻译和具体代价可以作为这些钩子的入口。不要用“真正可怕的还在后面”“事情远没有这么简单”“这只是第一层”制造空悬念。

## 爽感来自认知奖励

“网络小说般的爽感”不等于不断喊高潮。让爽感来自下面一种变化。

- 预期被修正，读者产生“原来如此”。
- 混乱被压缩，读者感觉“终于讲清楚了”。
- 隐秘经验被命名，读者认出“这就是我想说的”。
- 因果链闭合，读者明白“难怪会这样”。
- 行动突然清晰，读者知道下一步怎么办。

钩子必须来自内容，爽感必须来自理解变化。

## 宏观结构与局部问题链

复杂文章需要地图，但不要拿地图挡住风景。

- 宏观有结构。提前知道入口、核心解释、后果和行动出口。
- 微观不按模板。每段接住读者刚产生的自然问题。

局部问题可以沿下面的方向变化。

`发生了什么 → 为什么 → 凭什么 → 有无反例 → 与我何关 → 怎样行动`

不要机械走完全部问题。后一段只重复上一段时，文章没有推进。

## 段落是思想单位

两到四句只是常见工作尺度，不是写作定律。让段落用完成一个局部思想所需的自然长度。

用意义决定换段。时间、人物、讨论对象、局部问题或论证动作变化时再换。观点、根据、例子和限定共同回答一个问题时，让它们待在同一段。

单句成段只保留四种情况。

1. 前文充分铺垫后的真正落点。
2. 文章方向发生变化的真正转折。
3. 必须让读者停一下的关键事实或动作。
4. 文章最终收束。

连续三个短单句段必须人工检查。回答不出“为什么每句都必须停”，就合并。不要因为一句话适合截图，就让它独立成段。

让节奏呈现高低差。

`进入 → 展开 → 加速 → 落地 → 留白 → 再推进`

不要整篇保持“啪 → 啪 → 啪”的统一鼓点。

## 中文表达

- 先写谁做了什么，再补原因、时间和条件。
- 白话打底。古意、术语和成语只有比白话更准确时才用。
- 允许普通词自然重复，不为避重连续更换同义词。
- 动作已经表达情绪时少解释一句，给读者留下能自己走完的两步。
- 金句必须承担最终判断、情绪凝结、概念命名或因果压缩。只适合截图就删。
- 比喻必须提高理解准确性，不能只负责文学感。短距离内不要频繁切换战争、建筑、海洋、机器、道路和温度等世界。
- “不是……而是……”是高风险句式，不是绝对禁令。只有 A 确实被排除、B 确实被确认时才用。
- 冒号用于真实解释、列举和引出。破折号用于必要补充、转折和停顿。两者都不禁止，但不能靠它们反复宣布答案。

## 黑话分三级

### 默认删除

赋能、抓手、打法、拉通、认知跃迁、价值释放、组合拳、打开想象空间等纯装饰用法。

### 语境检查

生态位、范式、心智、方法论、核心变量、协同、链路、颗粒度、对齐等。准确表达专业本义时保留，用来给普通事情抬价时改写。

### 专业必要

行业真正需要的术语正常使用，并尽快说明它在当前问题里改变了什么。目标是使用最准确、理解成本最低的词，不是把所有词写得更土。

## 情绪和传播

传播性来自压缩价值。把复杂问题讲简单，把隐约感受讲准确，把争论讲透，或给出能解释世界的框架。

允许愤怒、讽刺、荒诞、感动和遗憾，前提是情绪由事实、动作和关系托住。脱口秀感来自观察准确、真实落差和语言节奏，不来自高频吐槽。

行动不等于喊转发收藏。可以提供认知行动、决策行动、行为行动或重新解释处境的叙事行动。
