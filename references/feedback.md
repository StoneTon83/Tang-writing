# 真实数据、瓶颈与内容进化

只基于用户提供或已授权读取的真实数据复盘。没发布或没数据时，做草稿风险诊断与下一次实验设计，不能编造阅读、打开、收藏、转发、关注、评论、掉读或收入表现。

## 先使数据可比

记录平台、内容、发布时间、观察窗口、实际能取得的指标及口径、分母、受众与分发条件。不同平台或不同观察窗口不能直接当同一基准。用户只给部分数据时保留缺失，不把阅读量当曝光，不把点赞当完读，不把关注当转化，不凭总阅读推断标题点击率。

内容 × 人群 × 时机 × 网络会共同影响表现。单篇异常不能直接证明某个结构有效；历史反馈也不能自动变成因果。下面是寻找问题的候选解释，不是无需检验的归因规则。

## 优先找最大瓶颈

沿看见 → 点击 → 继续读 → 获得价值 → 记住 → 愿意传播 → 跨关系复制查找最弱处，优先修它。

| 实际观察 | 候选解释 | 还应检查 |
| --- | --- | --- |
| 曝光低 | 分发或初始网络不足 | 可得曝光、来源与分发条件 |
| 点击低 | 题目、标题或目标人群不匹配 | 曝光分母、入口人群、标题承诺 |
| 开头掉读 | 阅读必要性弱或承诺未兑现 | 真实掉读数据、第一屏与正文关系 |
| 中段掉读 | 奖励密度不足、冗长或重复 | 掉读位置、段落功能和其他分发因素 |
| 点击高、完读低 | 承诺高于兑现 | 可比的点击、完读口径与受众变化 |
| 完读高、转发低 | 关系用途或传播许可弱 | 私人价值、敏感性、分享方式 |
| 收藏高、转发低 | 工具性或私人需求强 | 使用场景及社交风险，不能简单判失败 |
| 转发高、收藏低 | 社会表达价值较强 | 真实转发理由与内容类型 |
| 评论集中于某案例 | 张力可能在案例 | 评论原文、选择偏差与代表性 |
| 转发／阅读高、关注低 | 内容与作者关系未沉淀 | 关注归因、入口与后续关系指标 |
| 流量一般、老读者反馈强 | 高信用资产 | 核心读者反馈及长期趋势 |
| 阅读高、长期打开下降 | 可能透支信用 | 可比人群、窗口、平台和题材变化 |

没有所需指标时，明确该解释暂不能判断，提出最少补充数据。不要求用户补不存在或平台不可得的数据，也不把无法测量的“作者信用”压成假分数。

## 六问复盘

1. 哪个入口最有效？
2. 最大掉读点在哪里？
3. 读者真正记住了什么？
4. 他们为什么转发？
5. 哪个判断产生最大反馈？
6. 这篇改变了作者对读者的什么认识？

每项分别写实测证据、候选解释、缺失信息；未观察到记忆和转发理由时，不能靠作者猜测填成事实。评论是一类反馈，不自动代表全部读者。

把新增认识更新到张力雷达、选题判断和表达方式；记录读者的认知、情绪与关系用途。只在任务已授权的项目记录中更新，不未经请求写跨会话记忆。

## 实验与反退化

下一次改动先写：目标人群、预期读者行为、待检验假设、主要改动、能取得的指标、可比较条件、可能推翻解释的结果。没有正式实验条件时按观察性反馈处理，不称为因果检验，也不捏造收益阈值。

利用历史有效做法并保留探索。检查成功结构的重复是否已可预测；可尝试新主题、结构、文体、长度、叙事距离、观察对象或形式。重复价值，不重复套路；不根据短期奖励无限提高愤怒、敌我叙事或标题刺激。

系列可以让读者从不同现实多次检验同一种可靠方法。单篇负责进入与传播，系列积累理解和信用；二者的实际效果仍须真实反馈，不靠设定宣布“认知占领”。

交付时说清当期内容表现、对读者的新增认识和下一次可检验调整。没有后续打开、主动搜索或关系反馈等证据时，不宣布长期传播资本已提高。发布与分发建议可以交付；执行外部操作仍遵循本会话授权范围。
