# 读者与选题

## 选题六问

1. 谁会觉得文章在说自己？具体到处境，不能只写“普通人”“大家”。
2. 此刻具体痛、怕、气、馋、后悔或纠结什么？
3. 对他的现实利益有什么关系？
4. 他默认相信怎样的解释？
5. Tang 可以提供什么新增判断？
6. 谁会为什么转给另一个具体的人？

前三问不清楚，原则上暂不进入正式研究。用现有信息修题、缩小对象或列为待补；明确研究任务本身可以完成，不把公众号选题门槛扩成禁止其他研究。

多题竞争时比较这些答案的具体程度、利害的真实性、判断的增量和传播关系。不要编造爆款概率或加权总分。判断“题目值得研究”和“读者愿意点开”是不同工作。题目已锁定时优先寻找真实处境，不替换用户选择。

## 八项读者模型

| 项 | 要明确什么 |
|---|---|
| 目标读者 | 具体哪群人 |
| 现实处境 | 正在经历的事情 |
| 表层情绪 | 此刻感受 |
| 深层欲望 | 真正想得到什么 |
| 最怕失去 | 钱、机会、关系、尊严、时间、孩子、自由、选择等 |
| 默认解释 | 此前如何理解此事 |
| 认知更新 | 希望修正哪个判断 |
| 潜在转发对象 | 最可能发给谁、为什么 |

这是后台简短建模，未知项写假设，不假装已经访谈或已经知道全部读者心理。用户要规划可展示短表；要正文时让这些判断成为表达，不输出问卷。

## 利害与主发动机

问“如果继续不知道、继续误判或这样做，会付出什么代价”。仅有知识新鲜感通常不优先；好奇、身份认同、人物命运也能建立关系，不强制每题变成钱、阶层或孩子的焦虑。

共鸣、愤怒、焦虑、恐惧、不甘、欲望、身份认同、好奇、认知反转、实用收益、人物命运、现实冲突中选一个主发动机。其他情绪可随叙事变化，无需另立副发动机。研究、机制、案例支持核心判断；认知解释型内容的解释本身可驱动阅读。

现实利害不能虚张声势。条件性风险按条件表达，不把局部失利包装成命运必然。读者处境假设要在取材和真实反馈中修正。
