# 数据与复利

有真实数据时用本篇预设主爆点复盘，再看主动扩散和账号复利。没有数据时交付待验证假设与观察计划；不编后台数字、算法权重、获胜原因或“已验证母题”。

## 先核对口径

记录来源、文章、发布时间、观察窗、受众规模和已知分发条件。阅读人数与阅读次数、分享人数与次数、留言条数与人数、赞赏金额与人数、转载次数须分开；缺失不是零。只用可用且同口径的分母计算比率，没有曝光或送达数据就不能算点击率，没有完读数据就不估完读率。

优先与自己相近阶段、题材和观察窗的历史基线比较行为强弱，同时报告绝对量与可靠的相对表现；不设通用“爆款”阈值。粉丝增长、热点、投放、平台助推、作者自操作或少数高额赞赏会改变解释。没有来源拆分就不能认定全是自然传播，也不能把某行为高直接当作平台推荐因果。

## 把行为当诊断线索

| 观察 | 优先检验的解释 |
|---|---|
| 阅读高 | 选题、标题、时机或分发强；单凭阅读无法确定是哪一个 |
| 点赞高 | 低成本认同，未必愿意让别人看到 |
| 分享高 | 关系传播价值，找嘴替、帮人、提醒、身份表达 |
| 推荐高 | 愿意公开背书，找判断与公共价值 |
| 划线高 | 句子级可携带价值，核对到底哪些句子被划 |
| 留言高 | 经历、立场或争议被激活，读留言内容，分清价值与吵架 |
| 赞赏高 | 深度帮助、连接或作者认同；金额不能替代人数分布 |
| 转载高 | 编辑和账号认为内容值得再次分发，核对真实转载来源 |

这些是待检验解释，行为与心理不一一对应。分享、推荐、转载可带来扩散；点赞、划线、留言、赞赏主要帮助识别击中之处。主爆点没有高低等级，各项按文章预设判断。

## 找断点，只修短板

- 阅读与后续行为都低：先查送达、曝光等可用分发证据，再重审题目、标题和时机，别只改正文。
- 阅读高、分享推荐低：检验入口与传播价值；高曝光不等于标题已获验证。
- 阅读一般、划线高：检验入口、切入、受众规模，保留已有句子价值。
- 点赞高、分享低：认可尚未成为主动扩散，检查谁发给谁的理由。
- 分享高、划线低：整体情绪、关系或故事可能已足够强，不必强补金句。
- 留言突出、其他一般：检查是否只有争议，是否带来长期内容价值。
- 赞赏高、阅读不高：核对核心用户帮助与破圈入口，注意金额集中。

先回答“因为 X 产生 Y”的假设有没有得到支持，再列替代解释及下一轮最值得验证的一项。内部评分和作者自我感觉不替代市场，不把失败归咎于读者。

## 追赢家，积累基础盘

分别观察单项行为突出、主动扩散、账号增长。高阅读是一项结果；新增关注、后续相近文章的基础阅读、旧文回流和作者预期，才帮助判断是否形成复利。缺后续数据时增长效果待验证，不把一次热文提前称作增长赢家。

真实反馈显示某需求有效后，研究赢的是母题、人群、情绪、冲突、判断、标题、句子还是转发关系；证据不足时保留几个解释。优先围绕同一真实需求换场景、深挖机制、回答留言、处理反向问题或另一种处境，避免重复爆文或只复制标题外壳。资源向已验证赢家集中，保留少量新题探索；无数据时保留探索状态，不造赢家。

高势能母题应需求长期存在、Tang 有判断、能生出新问题、能接现实事件并获得自己的数据支持。热点进入母题，不为了热点抛掉作者定位。单次大阅读与抬高基础盘的文章按长期收益比较，不把原文举例数字当作固定门槛。

在用户已有资料库或本次授权成果中保留必要记录：题目与日期、实验假设、观察窗与基线、实际行为、有效句子或案例及来源、关键不确定性、下一题。已证实材料沉淀到母题、标题、表达、案例及候选池；失败保留反例。不自动访问后台、新建外部库或修改长期记忆。
