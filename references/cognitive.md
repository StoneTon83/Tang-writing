# Mode A：认知写作

交付更好的世界模型：读者再次遇到相似现实，会改变理解与判断。认知套利来自作者完成的研究、解释与压缩，不靠信息堆积或“反常识”口号。

## 搭建承重结构

内部先说清四件事：核心问题是什么，读者原来相信什么，准备给出什么新判断，哪些证据必须成立。若问题没有旧模型或新理解，先寻找真正的认知差。

优先形成这条逻辑：现实异常 → 旧解释出现问题 → 证据进入 → 机制解释 → 新模型 → 现实迁移 → 反例攻击 → 新判断。它是逻辑路径，不能机械拆成八节或把所有稿件写成相同次序。

开头让读者在具体事实中发现原有解释的冲突：原来同时相信的两件事情，为何不能同时成立？不要直接宣布“一个反常识真相”。熟悉感降低进入成本，新增理解带来回报；领先读者半步是传播距离的比喻，不是可测量指标。

## 给证据正确的工作

| 材料 | 可以承担的任务 | 常见越界 |
| --- | --- | --- |
| 故事 | 把问题放回现实 | 用感染力代替真实性 |
| 案例 | 证明某事确实发生 | 由单例推出规模或普遍规律 |
| 数据 | 显示规模、分布、变化 | 忽略样本、口径、时间及分母 |
| 研究 | 检验某种解释 | 把相关当因果、把实验条件外推到所有人 |
| 反例 | 攻击并收窄判断 | 只挑方便驳回的稻草人 |
| 机制 | 连接因果链 | 用流畅的解释冒充已经证明的机制 |
| 跨场景案例 | 检验迁移 | 只找与原命题表面相似的例子 |

按任务需要查验原始来源；没有读到论文、报告或原文，就不能声称已验证。资料过时、承重结论不确定或用户要求查证时补研究。无法获得关键来源时标记不确定，并采用证据能支撑的较小判断。

允许重新分类、命名、建立层级、连接不同研究与提出中层模型，但分开写原作者说了什么、研究支持了什么、Tang 推演了什么。新命名是作者的解释工具，不自动获得科学共识地位。

## 把理解带回读者现实

段落沿读者的疑问、抵触和下一问推进：这个证据解决了什么，又留下什么？案例长度应与它完成的工作相称；不让每个案例都无缝证明同一个结论。

每段带来新事实、解释、机制、判断、模型或应用。连续 300—500 字没有新回报是长文诊断信号，先查重复、冗长案例和解释停滞，不为凑频率硬加金句。

在新模型成立后安排现实迁移和最有力反例，明确适用边界。最终判断须解释读者原来无法解释的现实，而非仅多学了一个概念。

金句是高压缩比认知，可完成命名、压缩、解释、判断或迁移。证据先于金句；被截图或复述后仍须保留必要条件，不把有限结论压缩成无条件断言。

## 结束前核对

读者原来的哪个理解发生变化？变化有足够证据吗？他会拿这个理解解释什么现实？如果三问答不清，优先修命题和承重结构，再修标题。
