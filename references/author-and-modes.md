# 动态作者模型与写作模式

这份文件用于重要长文、跨项目写作和需要“按唐的方式判断”而不仅是“按唐的句式模仿”的任务。

## 动态作者模型

作者模型学习选择和判断，不复制历史句式。不要统计几个口头禅以后反复模仿，也不要把四个月前的文章冻结成永恒风格。

内部按四层理解作者。

### 世界观层

记录长期稳定的认识方式。

- 事实约束叙事。
- 信息不完备时仍要行动，但反对未经验证的确定性。
- 关注因果、成本、约束、反馈和长期后果。
- 不为迎合读者牺牲真实边界。

### 判断习惯层

观察作者如何处理问题。

- 从第一性原理追问前提。
- 区分事实、自述、推断和未知。
- 主动寻找最强反方、反例和边界。
- 愿意修正判断，不保护已经写顺的观点。

### 表达偏好层

保留相对稳定但允许演化的偏好。

- 简洁、直接、自然中文。
- 有明确判断，也承认不知道。
- 减少模板化翻案句、破折号和蹩脚引号比喻。
- 拒绝廉价鸡汤、假想敌和情绪绑架。
- 用意义决定换段，用论证需要组织节奏，不设固定段落句数。

### 当前项目层

让项目风格覆盖通用表达偏好，但不突破事实和隐私边界。

- `叙事八核` 提高叙事推进、嘴替感和传播性。
- 商业或产品分析提高正确性、信息密度和可执行性。
- 朋友圈提高真实性、经营者视角和个人判断变化。
- 认知、学习和研究型文章提高解释力、证据纪律、认知推进和可迁移性。

作者模型只从用户明确确认的选择、已接受的成稿和当前项目规则中更新。草稿、模型建议和未被用户采纳的版本不能自动升级为长期偏好。

当前公开写作优先服务尽快增加收入的现实目标。选题应考虑目标读者的真实需求、作者已确认的交付能力和获得有效反馈所需的投入，不默认长期只做立信内容、以后再考虑承接。这是当前资源配置约束，用户调整目标后随之调整；不能固化为作者的永久人格，也不能为了个人品牌把每个问题都写成既有世界观的证明。

作者出现，靠的是选了什么问题、怎样解释证据、愿意承担什么判断以及何处主动收住。可以提出备选立场让用户确认，不能把模型建议写成 Tang 已有信念；也不靠反复写“我认为”或编造业绩建立权威。

## 三种写作模式

先选主模式，再按任务混合。下面的优先级是工作选择，不是对文章质量的客观排名；模式决定注意力，不决定固定腔调。

### Mode A 分析型

适合商业、AI、产品、行业、社会议题以及以解释和判断为主的研究型内容。

优先级为正确性、判断、解释力、信息密度和阅读体验。先建立事实口径、关键关系和因果链；公开任务可在选题时检验传播假设，但不能让它决定研究结论。

认知文章通常仍以 A 为底，不单独新增第四种模式；额外读取 `references/cognitive-writing.md`。认知写作是一种任务方法，不是固定口气。

### Mode B 叙事型

适合人物、真实经历、关系和“叙事八核”。

优先级为真实材料、叙事推进、判断、情绪、表达。让人物动作、关系变化和后果承担情绪。

### Mode C 传播型

适合公众号、自媒体和公开短内容。

优先级为价值密度、阅读驱动力、嘴替感和可传播性。始终服从事实边界，不用标题党和情绪操纵换打开率。

`叙事八核` 默认使用 B 加 C，并保留 A 的事实与逻辑底线。商业评论通常以 A 为主，按需要加入 C。个人经历通常以 B 为主，只有公开发布时才增加 C。认知类公众号通常以 A 为主、C 为辅；不要因为公开发布就把它改写成情绪驱动或动作清单。

## 写作前的模式检查

写作模式与公开任务分别选择。A/B/C 决定怎样组织材料，G 增长、T 立信、M 转化决定本篇主要争取什么结果，具体验收见 `references/attention-and-distribution.md`。例如分析型文章可以承担增长，决策型方法文可以承担转化，叙事型文章也可以立信；不把 Mode C 与增长画等号，不要求一篇同时完成三个任务。

在内部回答下面四题。

1. 当前主模式是什么。
2. 哪个项目层或任务模块需要覆盖通用风格。
3. 这篇文章最不能牺牲的质量是什么。
4. 哪一种模式倾向最可能让文章失真。

公开内容再简要确定主任务、目标读者和阅读动力；已确认的信息直接沿用，不把内部判断清单变成用户问卷。一个主任务可以带一个次任务，资源分配以主任务为准。

不同文章不能全部写成一种口气。保持作者的判断方式，比保持固定句式更重要。
