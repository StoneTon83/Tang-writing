# 3.1 隔离前向回归：协作语料归属

状态：通过研究设计与结构草案阶段；没有把它扩大为完整成稿通过。

## 测试目的

验证 Tang Writing System 3.1 面对一份来源链混杂的第三方电子书时，能否先清洗材料和作者归属，再研究可迁移方法；同时检查它是否会把目录项直接当原创文章、把转述稿句式归给主讲者，或为了满足“研究某人的写作”而越过证据。

## 隔离输入

测试者只得到下面的用户场景。

- 一份第三方汇编的知识专栏 EPUB，共 300 个目录项。
- 已知存在重复章节、图片误作章节、拼接内容和异常来源。
- 前半部分主要署名为主讲者，后半部分明确标注另一人转述，全书还可能经过编辑。
- 用户要求深度研究主讲者的写作，并总结可迁移方法。

测试者只能读取 `SKILL.md` 及其按需路由的 references，不读取升级审计、tests 或 Git 差异，也不编辑文件。

## 实际路由

测试者读取了：

- `references/voice-and-method.md`
- `references/author-and-modes.md`
- `references/cognitive-writing.md`
- `references/facts-and-materials.md`

它没有读取完稿修订、公众号和朋友圈参考，因为任务仍处于研究方案与结构草案阶段，没有第一稿，也没有指定发布场景。按需加载成立。

## 实际决策

### 1. 先改写研究口径

测试者拒绝把 300 个目录项直接叫作 300 篇原创文章。它先把条目拆成真实章节、重复项、图片误识别、拼接项和未知项，并要求拼接内容继续按段落拆分。

### 2. 把文本生成链拆开

测试者建立“主讲、转述、实际写作、编辑、汇编”的归属账本，并区分三档语料。

- 能与原稿、录音或可靠逐字稿互证的高置信材料。
- 署名清楚但编辑边界未知的中置信材料。
- 他人转述、拼接或来源异常的低置信材料。

低置信材料只用于寻找待验证线索，不承担句式与文风结论。

### 3. 把“写作研究”收窄到证据能支持的层级

测试者认为，清洗后的材料可以研究选题、判断、知识组织、讲解模型、证据安排、反例和边界；找到原稿或可靠逐字稿以前，不能总结主讲者的句式、节奏、口头禅和表面声音。

它同时提出最强替代解释：所谓稳定文风可能主要来自统一的转述模板或编辑加工。验证办法是对照原始材料、比较不同署名组并检查跨版本稳定性；无法区分时继续降低结论强度。

### 4. 交付没有变成模仿模板

结构草案沿“来源问题、文本生成链、稳定方法、反证验证、可迁移判断”推进，但没有要求每篇文章固定使用这一顺序，也没有输出人物口吻、固定句式或所谓风格配方。

## 回归结论

通过。3.1 的协作归属、来源质量、最强反方和证据强度规则实际改变了研究计划，并阻止了三种高风险行为：目录计数冒充原创篇数、内容归属冒充句子归属、转述与编辑痕迹冒充个人文风。

本项只验证研究设计、归属口径和结构草案。测试输入没有提供 EPUB 正文、原始录音、原稿或编辑说明，因此没有实际完成风格结论和成稿；不能把本项记录为完整端到端写作通过。
