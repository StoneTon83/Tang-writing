# 3.0 端到端回归测试：可逆选择

状态：通过。已完成从选题、研究、论证、起稿、四遍改稿、事实核验到盲审的完整流程；得到公众号成稿，但未发布。

成稿：[`tests/fixtures/reversible-choice-article.md`](fixtures/reversible-choice-article.md)

## 测试目的

验证 Tang Writing System 3.0 能否在没有现成个人故事的情况下，以一个真实决策困境为起点，完成研究型认知文章的全流程，同时满足五项要求。

1. 研究足以承担主判断，却不把正文写成文献综述。
2. 标题、案例和结尾不比证据走得更远。
3. 最强反方会实质修改主张，不只是补一句“也有例外”。
4. 读者最后获得可迁移的判断方法，而不是只记住案例和金句。
5. 发现缺口时先判断现有规则能否处理，不为单篇文章继续增加模板。

## 材料账本

### F1 可核验公开事实

- Amazon 2015 年股东信中的单向门、双向门比喻。
- Howard 的信息价值理论，Arrow 与 Fisher 关于不确定性、不可逆性和未来选项的模型，Roberts 与 Weitzman 关于分阶段投入、学习和停止权的模型。
- NASA COTS 的多方协议、里程碑、Rocketplane Kistler 终止事实、已支出 3210 万美元与协议最高 2.07 亿美元。
- NASA 官方管理史对阿波罗启动时短暂共识、期限纪律、合同、组织和关键管理者的记录。
- Shin 与 Ariely 关于维持低价值选项的“门游戏”。

### I1 作者推断

- 重要选择除了眼前收益，还要计算信息价值、未来选项以及退出、等待和维持选项的成本。
- “能改”不等于无损撤销，而是发现判断有误时仍能停止、缩减或转向。
- 小步行动只有在反馈先于下一笔重要承诺、反馈能区分判断且退出权真实存在时，才构成可逆试验。
- 可逆性适合探索阶段；当新增信息不再改变方案排序，且留门成本开始超过继续求证的价值时，承诺可能创造更多价值。

### U 未知与禁止补写

- 没有用户确认过的辞职、创业、买房、关系或项目试错经历。
- 不补第一人称故事，不把通用场景伪装成作者亲历。
- 没有证据证明“可逆选择普遍优于不可逆选择”，因此正文必须保留等待成本、选项成本、试验失真、他人承担退出成本和承诺价值。

## 论证简报

### 1. 读者起点

重要选择通常被当成一道事前必须答对的单选题。常见做法是继续列利弊、搜集资料，直到认为自己足够确定。

### 2. 真实问题

决定选择好坏的关键信息，经常只能在行动后出现。人在无法事前看清全部未来时，怎样开始行动，又避免在新证据到来前把全部筹码压上去？

### 3. 最小认知模型

先区分信息怎样出现，再判断等待、试验还是承诺。

- 时间本身会带来能改变行动的信息，而且机会仍在、延迟成本低：等待可能有价值。
- 信息只能通过行动获得，而且试验足够真实、反馈先于扩张、退出权可信：先做可逆试验可能有价值。
- 试验删掉了信任、持续投入或协作等必要条件：小试验可能产生误导性坏证据。
- 新增信息已经很难改变方案排序，维持选项和延迟投入的成本更高：减少选项或承诺可能更有价值。

所以，主张不是“凡事留后路”，而是让关键证据尽量赶在更大承诺之前出现，并在证据足够以后停止比较。

### 4. 关键证据及功能

| 材料 | 正文功能 | 不能证明什么 |
|---|---|---|
| Amazon 单向门、双向门 | 提供读者熟悉的命名入口 | 不是科学证据，也不能决定个人选择 |
| Howard、Arrow–Fisher、Roberts–Weitzman | 支撑信息价值、不可逆性、分阶段学习与停止权 | 是规范模型，不能自动外推为所有人生建议 |
| NASA COTS | 展示里程碑如何把付款与进展绑定，并保留退出通道 | 不能证明分阶段没有损失或一定成功 |
| Shin–Ariely 门游戏 | 证明人可能为维持低价值选项持续付费 | 低风险实验不能直接决定职业、关系和投资 |
| NASA 阿波罗管理史 | 展示期限和清晰目标在大型协作中的协调价值 | 不能证明承诺本身足以导致成功 |

### 5. 最强对手

可逆性不是免费保险。维持选项会消耗注意力、资源和信任；一些信息只有真正承诺以后才会出现；过轻的试验可能低估需要长期投入才出现的价值；一个决定还可能只对决策者可逆，却把损失转给伴侣、团队、客户或合作者。

这些反方不是结尾限定，而是直接改变模型：可逆试验需要最低充分承诺，退出成本必须包含他人承担的部分，探索也必须有停止条件。

### 6. 认知路径

文章从“重要选择为什么无法事前想清楚”进入，先把选择价值扩展为四笔账，再用 COTS 解释可逆试验的机制；随后区分被动等待和主动试验，引入选项成本与承诺价值，最后压缩成四个可迁移问题。

正文没有按研究来源分类，也没有照着论证简报的七项顺序成文。

### 7. 迁移

读者最后可以带走四问。

1. 什么新信息会改变决定？
2. 这些信息靠等，还是靠做才能得到？
3. 下一笔难以撤回的投入之前，退出点在哪里，谁为退出付钱？
4. 这扇门继续开着要付什么租金，什么时候应该关？

## 素材策展结果

研究阶段还检查了斯德哥尔摩拥堵税试点、FBI Virtual Case File、探索时域、可更换选择与满意度、截止期限、承诺储蓄等材料。它们帮助检验边界，但没有全部进入正文。

- 删除 Gilbert 与 Ebert 的摄影、海报实验。它与门游戏、选项成本和阿波罗连续出现时，正文开始像文献综述；删去后边界没有丢失。
- 不采用斯德哥尔摩和 FBI 案例。两者会增加案例数量，却不能比 COTS 更清楚地解释“反馈先于承诺”。
- 不加入截止期限和承诺储蓄的统计细节。它们支持预承诺在特定任务中的价值，但正文已有阿波罗承担协调反例，再加入只会提高研究展示密度。

这验证了“研究阶段追求充分，正文阶段追求选择”。

## 四遍改稿记录

### 审真

- 将“3210 万美元是真实损失”改为“终止时已经支出 3210 万美元”，避免把支出直接等同损失。
- 将“每个里程碑都会重新决定更大投入”收窄为“里程碑把付款与阶段性进展绑定，并保留必要时退出的通道”。
- 将阿波罗的“政治承诺导致协调”改为来源实际支持的“短暂共识、期限纪律、清晰目标与组织协调”。
- 把门游戏后的机制解释改为“可能”“未必”，区分实验观察与文章推断。

### 审理

- 将局部的“判断标准只有一个”限定为判断“该等还是该试”时的判据，避免与后文的选项成本冲突。
- 增加“试验也要足够真实”，防止把小步行动写成天然正确。
- 增加“谁为退出付钱”，防止只从决策者角度计算可逆性。
- 把停止探索的条件改为可观察标准：新增信息难以改变方案排序，且留门成本已经超过继续求证的价值。

### 审路

- 删除低必要度的摄影、海报实验，保留 COTS、门游戏和阿波罗各自独立的材料功能。
- 合并无意义短段，保护“没有一次性把整场错误买完”和“只有切段……只是分期付款”等真正承担压缩功能的句子。
- 删除“关上一些门，走进去”的泛化金句，让结尾停在证据足够以后投入这一判断上。

### 审文与交付

- 初稿检查结果：汉字 2472，段落 60，翻案句 4；需要人工复核冒号、问号、洞察路标和连续短单句段。
- 成稿检查结果：汉字 2676，段落 53，翻案句 1，同构排比、名词化、抽象抒情、破折号、模型路标、黑话、情绪绑架和鸡汤均为 0。
- 成稿仍提示冒号 22、抽象引号 12、洞察路标 5、问号 10 和连续 3 个短单句段。人工复核后保留：冒号主要来自四笔账、四问和参考资料说明；引号用于已定义术语；问号用于标题、真实问题和四个判断问题；短段提醒来自参考资料列表，不构成正文口号鼓点。

检查脚本未使用 `--strict`，结果作为烟雾报警器而非写作评分。

## 隔离前向测试

测试者只读取成稿，或只读取已安装 Skill 及其按需路由的参考文件；均未读取本文件和升级审计。

### 普通读者盲审

盲审者读完后留下的核心判断是：“小步走”不等于可逆，只有反馈先于重大承诺且真的有权停止，才叫可逆试验。标题被正文兑现，COTS 是最有说服力的部分。

盲审发现三项问题：局部判据被写成全文唯一标准，反方段研究堆叠，结尾金句过度。三项均已修改。

### Tang Writing 3.0 前向审查

隔离测试认为文章已完成真实问题、研究证据、机制、最强反方和迁移的主闭环，但发现“对谁可逆”“小试验可能失真”和停止探索标准不够可观察。三项均由现有的最强对手、边界、材料功能和迁移检查发现，并已进入成稿。

### 一手事实审查

事实审查逐项核验 Amazon、COTS、门游戏和阿波罗来源，发现 COTS 支出被误写成损失、里程碑决策被写得过强、阿波罗承诺表述越过来源。修正后，审查者确认门游戏解释已保留必要的可能性措辞；最后两项指定修正也已逐字落实，事实边界通过。

### 最终盲审

最终测试者未发现必须修改的问题，认为标题与主张已兑现且不过界，材料分别承担概念、机制、反例和边界功能，没有明显文献堆叠、模板感、逻辑冲突或结尾过度，可以作为公众号成稿进入验证归档。

## 回归结论

端到端测试通过。

- 3.0 能从真实问题建立最小认知模型，并让研究服务于解释。
- 最强反方确实改变了主张，最终文章同时处理探索、等待、试验、退出、他人成本和承诺。
- 材料策展有效阻止了正文向文献综述滑动。
- 四遍改稿能够同时处理事实强度、机制边界、论证推进和自然中文。
- 读者离开案例后仍能保留四个可迁移问题。

本次没有修改 `SKILL.md` 或 references。验证暴露出的缺口都被当前 3.0 已有规则发现并修正；为“可逆选择”单独新增规则只会造成选题级过拟合。

本项只记录端到端回归结论：它通过，但不改变成功经验回归“核心机制通过、标题边界部分通过”的事实。版本、安装和 GitHub 生命周期统一以 `UPGRADE_AUDIT_3.0.md` 的“当前状态”为准。
