# Tang Writing System 4.2

2026-10-07。为“哥的八核猜想”及 Tang 的公共写作制作的内容生产 skill。以真实传播行为与账号复利为中心，从最新4.2结论独立编写，此前TWS不参与执行。

核心链路：竞争高势能选题 → 具体读者、主心理发动机、主爆点 → 研究与判断 → 持续阅读收益与可携带价值 → 标题竞争 → 真实数据复盘 → 追赢家、积累母题和账号基础盘。

## 安装与使用

将以下7个运行文件放入 Codex 全局 skills/tang-writing-system 目录：

- SKILL.md
- agents/openai.yaml
- references/topics-and-behavior.md
- references/facts-and-judgment.md
- references/content-and-expression.md
- references/data-and-compounding.md
- references/system-source.md

替换已安装版本时先检查独有修改并保留恢复材料，旧文件移出技能加载目录，不能在旧目录上叠加复制后留下旧参考。维护用README、AGENTS、发布记录和历史许可不必安装。

使用 `$tang-writing-system`，例如“比较这几个选题的传播潜力”“按材料起草这篇文章”或“依据这份真实后台数据复盘并规划下一题”。支持普通自动选择。需要在新的会话中核对实际技能发现，不能把文件存在当成已完成触发测试。

入口按任务读取参考。用户要正文时只交付正文；保留锁题、成熟稿、局部改稿和材料边界。缺实际数据时输出假设和待验证事项，不捏造赢家。

## 本版原则

每篇确定一个主心理发动机和一个主爆点，从分享、推荐、划线、留言、赞赏、转载中选择最有希望突出的行为，并有具体扩散理由。分别提供切身价值、阅读价值、传播价值与作者判断信用，不要求所有指标同时突出。

重要内容单元争取可携带的嘴替、判断或机制压缩，保留自然完整段落。用自己的历史基线诊断短板，资源优先投入已验证需求，同时保留新题探索。高阅读、主动扩散和长期增长分别判断；不猜算法权重、不承诺篇篇必爆。

真话不全说，假话全不说。可省略次要背景，不得隐去改变核心结论的事实；研究形成 Tang 愿意负责且可被现实修正的判断。

## 维护与边界

SKILL与四个工作参考是执行入口；system-source原样保留4.2的21章结论，仅供维护溯源，其原始碎行不作为文章模板。版本与界面字段须一致。检查结构、引用、来源、实际任务结果及安装镜像；发布验证见 [RELEASE_4.2.md](RELEASE_4.2.md)。

本仓库不包含私有聊天、账号后台数据、试用输出或安装备份。历史许可保留在 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。上传、公开发表、访问私有后台和联系他人遵守当前授权，skill本身不授予权限。视觉与独立贴图由项目策略和任务另行控制。
