# Tang Writing System 4.0

2026-10-01修订，版本维持4.0。面向“哥的八核猜想”的中文写作，先选题，每篇只选共鸣、认知、人物与现实、机制中的一个发动机，多数文章先考虑共鸣。

## 使用

调用 `$tang-writing-system`，给出真实材料、写作或改稿要求。可以比较选题，也可以直接承接已定题目；成稿保留Tang的感受、幽默、锋芒与审美，不强行给方法或升华。

本skill包括7个运行文件：入口、UI配置、选题、事实与研究、成稿审查、朋友圈、17章定稿原文。标题保留必要承诺设计；排版、上传、渠道、发布时间、增长实验和运营数据不在主体范围。

## 本次替换

原31章认知主链版被最新17章写作基线替换。删除6个旧参考：cognitive、engines、feedback、narrative、review、strategy；新增topics、reality-and-research、editing。不保留P0—P10、多作者内容能力矩阵、主辅传播引擎或运营复盘模块。

研究保持当前可靠证据标准，服务于校准；人物与故事支撑选定的主要回报，不扩成第二发动机。明确性质的虚构或综合人物可用，不伪装真实个案与作者亲历。

维护以本仓库main为发布来源，修改通过功能分支与PR合并，再同步本机制作源、安装包和全局安装目录。旧内容可在Git历史恢复。文件和行为验证不证明真实点击、共鸣或爆款。
