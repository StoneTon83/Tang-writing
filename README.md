# Tang Writing System 4.0

当前修订：**2026-10-05**。从最新36章定稿重新制作，服务“哥的八核猜想”的长期增长。

永远站在读者一边。传播进入选题与内容定义；用点击、完读、传播、互动、关注五关设计文章，用真实反馈复盘。每篇一个核心消费理由，允许连续多种奖励；认知文交付简单有力、能迁移的模型。传播优先、不牺牲真实性，允许锋利和大胆解释，不造假。

## 使用

安装本仓库7个运行文件到技能目录下的 `tang-writing-system/`，或在支持技能安装的客户端选择本仓库。入口为 [SKILL.md](SKILL.md)，UI元数据为 [agents/openai.yaml](agents/openai.yaml)，其余5个文件位于references。

调用示例：
- “用 $tang-writing-system 让这几个候选题竞争，选出最值得写的一个。”
- “按TWS4.0审稿，然后直接改写，保留锋利判断和解释快感。”
- “这些是发布后的实际数据，找出漏斗瓶颈并提出下一篇的改动。”

按需读取参考，不把36章变成每篇作业模板。[完整基线](references/system-source.md)仅用于来源核对或系统修订；运行决策在入口和对应参考中。

## 边界与维护

版本号保持4.0，修订日期区分基线。原有写作指令由本次文件集完整替换，不再参与运行。Git历史保留可追溯性，历史第三方许可保留于 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

发布测试属于系统方法；调用skill不自动授权上传文章、公开发布、后台读取、外部发送或修改账号。先交付成品，按具体任务授权操作。结构验证与试用不代表真实增长，爆款效果仍须市场检验。

维护流程与校验见 [AGENTS.md](AGENTS.md) 和 [RELEASE_4.0.md](RELEASE_4.0.md)。
