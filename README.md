# Tang Writing System 4.0

修订日期：2026-09-30。版本号保持4.0，调用名称为 `$tang-writing-system`。

在真实性、长期信用和作者人格不受损的前提下，提高高传播内容出现的概率，并积累 Tang 的认知资产、人格信用与解释权。现役依据是“梳理写作系统”最新31章总基线。

核心认知链：全球当前可靠证据 → 机制拆解 → 中国读者熟悉的现实 → 最强反例与边界 → Tang 愿意负责的判断。系统闭环：现实 → 张力 → 研究 → 机制 → 判断 → 编码 → 传播 → 反馈 → 进化。

## 使用

入口是 [SKILL.md](SKILL.md)。支持认知写作、非虚构叙事、朋友圈，以及选题、改稿、审稿、传播设计、系列规划和真实数据复盘。按任务加载参考，不要求每次展示全部工作表或把P0—P10写成十一节文章。

认知研究优先采用全球范围当前高质量证据，检查经典结论的更新与重复验证；案例优先选择中文读者熟悉的现代、历史或文化材料。故事帮助理解和传播，不能替代科学证据。

内容发动机按问题调用能力，避免拼接作者文风；一个主内容发动机配1—3个必要辅助，与一个主传播引擎、最多一个辅助的限制分开。事实核验、作者判断与品控始终有效。

## 安装范围

将下列10个运行文件保持目录结构，放入名为 `tang-writing-system` 的skill目录：

```text
SKILL.md
agents/openai.yaml
references/
  cognitive.md
  narrative.md
  moments.md
  strategy.md
  engines.md
  review.md
  feedback.md
  system-source.md
```

仓库地址沿用 `Tang-writing`，skill名称以frontmatter为准。仓库规则、版本记录、许可说明和Git格式配置不复制进安装目录。
